# Боты мини-игр Dota 2 — Dark Carnival

Два бота, которые играют в мини-игры ивента **Dark Carnival** вместо вас:
смотрят в экран, распознают происходящее и жмут клавиши.

| Бот | Мини-игра | Что делает | Лучший результат |
|---|---|---|---|
| **Арканоид** | «Сапожный снос» | ведёт тележку под мяч, проходит уровни | **37 690 очков, уровень 30** |
| **Печаталка** | «Атака автоматонов» | читает слово над врагом и печатает его | 212 слов за партию |

Рекорд арканоида — 37 690 очков при личном рекорде владельца аккаунта 1 640.
Это одна непрерывная партия: бот сам нажал «Играть», прошёл 29 уровней, терял
мяч 39 раз и продолжал. Мяч виден в 91% кадров, разбор кадра — 3 мс.

## Что нужно

- **Windows** (используются WinAPI: BitBlt, SendInput, GetAsyncKeyState)
- **Python 3.9+**
- **Dota 2 в оконном или «без рамки»** режиме. В эксклюзивном полноэкранном
  снимок экрана будет чёрным, и бот не увидит игру.
- **Разрешение 1920×1080.** Панель мини-игры находится сама, но пороги
  распознавания мяча заданы в абсолютных пикселях (размер пятна, отступ от
  стен, радиус поиска). На меньшем разрешении арканоид будет мазать.
- **Английский клиент — для печаталки.** Она читает только латиницу (`A-Z`),
  словарь — английские имена героев и предметов. Арканоиду язык безразличен.
- **Tesseract OCR** — [сборка UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki).
  Без него арканоид играет (просто не читает счёт и уровень), а печаталка не
  работает вовсе.
- **Идущий ивент Dark Carnival.** Мини-игры доступны только пока он в клиенте:
  «Игротека» → мини-игры справа внизу.

```bash
pip install -r requirements.txt
python run.py doctor     # проверит питон, библиотеки, tesseract и окно игры
```

Tesseract ищется сам: рядом с проектом (`Tesseract-OCR\tesseract.exe`), в
`Program Files`, в `%LOCALAPPDATA%`, в переменной `TESSERACT_EXE`, затем в
`PATH`. Свой путь можно прописать ключом `tesseract` в `config.json`.

## Как запустить

```bash
python run.py            # меню
python run.py boot       # арканоид
python run.py typer      # печаталка
python run.py boot --dry # вхолостую: всё видит и считает, но не нажимает
```

Или двойным кликом:

| Файл | Что делает |
|---|---|
| `Меню.bat` | меню выбора |
| `Арканоид — играть.bat` | боевой режим арканоида |
| `Арканоид — вхолостую.bat` | всё видит, но **не нажимает** клавиш |
| `Печаталка — играть.bat` | боевой режим печаталки |
| `Печаталка — вхолостую.bat` | сухой прогон |
| `Проверить окружение.bat` | диагностика |
| `Тесты.bat` | прогон тестов |

**F10 — старт/стоп, F12 — выход.** Клавиши читаются глобально (пока бот
запущен), жать можно прямо из игры.

### Первый запуск — по шагам

1. Откройте мини-игру и доведите до экрана правил с кнопкой «Играть».
2. Запустите **вхолостую** (`--dry`). Бот ничего не нажмёт, но в консоли
   покажет, что распознал: положение мяча, тележки, счёт.
3. Убедитесь, что в строках появляется `мяч+`, а не только `мяч-`.
4. Запускайте боевой режим. Дальше он сам: кликает «Играть», ловит фокус,
   играет, после проигрыша жмёт «Сыграть ещё».

Что бот делает с вашим вводом, чтобы это не стало сюрпризом:

- **кликает мышью внутрь панели** — иначе мини-игра не получает клавиши
  (см. ниже); в этот момент лучше не двигать мышь;
- **переключает раскладку окна игры на английскую** (`force_en_layout`) —
  иначе печаталка вводила бы кириллицу;
- **держит клавишу A или D нажатой**, пока ведёт тележку. Останавливайте бота
  через F10/F12 — при этом клавиши гарантированно отпускаются.

## Про баны — читать обязательно

Боты **не трогают память игры, не инжектят DLL и не подключаются к сети Valve**.
Они делают ровно то же, что человек: снимают картинку с экрана и отправляют
нажатия клавиш через штатный `SendInput`.

Тем не менее: **вы используете это на свой страх и риск.** Если аккаунт
получит ограничение — это не ответственность авторов проекта. За время
использования банов не было, но гарантий никто дать не может: правила Valve
формально запрещают автоматизацию клиента, и решение всегда за ними.

Здравый смысл: мини-игры Dark Carnival — развлечение внутри клиента, преимущества
над другими игроками бот не даёт, кроме места в таблице рекордов самой мини-игры.
В матчах это использовать нельзя, и бот к ним не приспособлен.

## Как это работает

### Арканоид («Сапожный снос»)

Мяч ищется **разницей соседних кадров** — двигается только он. По двум
последним позициям считается скорость и предсказывается точка пересечения
линии платформы **с учётом отскоков от стен** (зеркальная развёртка — одна
формула вместо пошагового моделирования). Просто ехать за мячом нельзя:
тележка идёт ~200 px/с, мяч быстрее и пересекает поле раньше.

Когда есть запас времени, мяч принимается **краем** платформы, чтобы послать
его в сторону оставшихся блоков; когда времени в обрез — центром, потому что
краем промахнуться проще.

### Печаталка («Атака автоматонов»)

Над каждым врагом висит слово; у текущей цели ниже идёт строка прогресса, где
**серые** буквы уже набраны, **жёлтая** — следующая, **белые** — остаток.
Бот берёт жёлтую и белые: это ровно то, что осталось напечатать, поэтому
набранное не вводится повторно.

Дальше маска букв уходит в Tesseract (whitelist A-Z), а результат чинится по
словарю героев и предметов Dota — но **якорно**: слово целиком правится по
словарю (`LEUS` → `ZEUS`), а остаток подгоняется только к суффиксам текущего
слова. Искать остаток по всему словарю нельзя — на живом прогоне `MAELSTR`
превращался в `MASTER`, а `ITE` (хвост FROSTBITE) в `IT`.

Неожиданная находка: враги несут не только имена, но и **целые реплики** —
«HAHA I COULD EAT A WALRUS», «AXE LIKES THIS VERY MUCH». Они длинные, а очки
растут с длиной текста, так что это самые ценные цели. Словарь для них не
нужен: печатаются как есть.

## Что было неочевидно (и стоило отладки)

Эти вещи не гуглятся — каждая найдена замером на живой игре.

**Мини-игра не получает клавиши, пока по её панели не кликнули мышью.**
При окне доты в фокусе синтетические A/D/Space не двигали платформу вообще
(замер: сдвиг ровно 0.0 px). После клика внутрь поля — поехала. Panorama до
клика просто не отдаёт панели клавиатурный фокус.

**Захват экрана стоит 16.7 мс независимо от размера области.** Это ожидание
кадра монитора, а не копирование пикселей: снимок вдвое меньшей области стоит
столько же. Значит захват надо выносить в поток, а не оптимизировать размер.

**Один проход OCR по HUD стоит 322 мс.** В главном цикле бот на треть секунды
слеп и пропускает мяч. Тоже вынесено в поток.

**Движущийся мяч даёт ДВА пятна разницы** — «ушёл» и «пришёл». Брать первое
попавшееся значит целиться туда, откуда мяч уже улетел. Нужное выбирается по
прогнозу полёта, а при потере трека — по маске посветления (место прибытия).

**Размер имеет значение.** Пятно мяча по замеру — 1700–2300 px, а фильтр
разрешал от 60: трек перехватывали искры от сбитых блоков, и платформа уезжала
не туда (в логе: цель 694, мяч упал в 390). Сейчас окно фильтра 700–4200 px —
верх с запасом, потому что при пропущенном кадре «ушёл» и «пришёл» слипаются
в одно пятно.

**С 4-го уровня кладка каменная, не оранжевая.** Состояние «идёт игра»
определялось по доле оранжевого — и живой уровень принимался за меню. Теперь
признак другой: тележка, она есть только в игре.

**Мини-игра сама встаёт на паузу, когда дота теряет фокус.** Снять её можно
только F9 — и только когда окно снова впереди.

**Консоль бота нельзя ставить вплотную к панели.** Светлое окно рядом
склеивается с панелью в один контур при морфологическом замыкании, и панель
перестаёт находиться. Зазор 45 px, ядро замыкания уменьшено до 9×9.

## Тесты

```bash
python -m pytest tests -q
```

224 теста: чистая математика (отскоки, предсказание, починка слов), зрение на
**настоящих кадрах игры** и сквозной прогон на синтетическом кадре. Почти
каждый баг из живых прогонов закрыт отдельным регресс-тестом — в тестах прямо
написано, что именно ломалось.

Набор проверен мутациями: в ключевые функции вносили заведомые ошибки (убрать
отражение от стен, поменять местами «влево/вправо», снять порог похожести
слов) и смотрели, упадут ли тесты. Две пережившие мутацию дыры закрыты
отдельными тестами.

## Настройки

`config.json` рядом с проектом (файл необязателен, дефолты — в `config.py` и
`boot.DEFAULTS`). Ключи можно класть в корень; настройки арканоида можно
дополнительно перекрыть секцией `"arkanoid"` — она главнее.

```json
{
  "tesseract": "C:\\Program Files\\Tesseract-OCR\\tesseract.exe",
  "dict_correct": true,
  "arkanoid": { "paddle_speed": 200.0, "aim_offset": 0.35 }
}
```

| ключ | чей | смысл |
|---|---|---|
| `tesseract` | оба | путь к `tesseract.exe` (пусто — искать самому) |
| `window_title` | оба | часть заголовка окна игры (`Dota 2`) |
| `hotkey_toggle` / `hotkey_quit` | оба | коды клавиш старт/стоп и выход (F10 / F12) |
| `loop_fps` | оба | частота опроса. Печаталка — 25, арканоид — 120 (кадры приходят каждые ~17 мс) |
| `paddle_speed` | арканоид | скорость тележки, px/с (замер: 200) |
| `dead_zone` | арканоид | насколько близко к цели считать, что доехали |
| `aim_offset` | арканоид | базовое смещение приёма мяча (0 — центром) |
| `focus_click` | арканоид | доля поля, куда кликать для захвата фокуса |
| `dict_correct` | печаталка | чинить ли слова по словарю Dota |
| `region` | печаталка | область экрана вручную, `[x, y, w, h]` |
